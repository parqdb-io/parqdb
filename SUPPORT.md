# Support

ParqDB is an early-stage open-source project. Community support is provided on a
best-effort basis through GitHub:

- use the [question form](https://github.com/parqdb-io/parqdb/issues/new?template=question.yml)
  for installation, API, and usage questions;
- use the [bug report](https://github.com/parqdb-io/parqdb/issues/new?template=bug_report.yml)
  for reproducible incorrect behavior; and
- use the [feature request](https://github.com/parqdb-io/parqdb/issues/new?template=feature_request.yml)
  for new capabilities or specification changes.

Search existing issues before opening a new one. Include the ParqDB version,
environment, minimal code, relevant schemas, and complete error output when
applicable.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not
be disclosed in a public issue. Conduct concerns follow
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
