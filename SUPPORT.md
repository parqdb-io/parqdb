# Support

ParqDB is an early-stage open-source project. Community support is provided on a
best-effort basis through GitHub:

- use [GitHub Discussions (Q&A)](https://github.com/orgs/parqdb-io/discussions/new?category=q-a)
  for installation, API, and usage questions;
- use the [bug report](https://github.com/parqdb-io/parqdb/issues/new?template=bug_report.yml)
  form for reproducible incorrect behavior; and
- use the [feature request](https://github.com/parqdb-io/parqdb/issues/new?template=feature_request.yml)
  form for new capabilities or specification changes.

Questions belong in Discussions. Defects and feature requests belong in Issues.
Search existing discussions and issues before opening a new thread. Include the
ParqDB version, environment, minimal code, relevant schemas, and complete error
output when applicable.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not
be disclosed in a public issue or discussion. Conduct concerns follow
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
